## 📱 スマートフォンでの利用手順 (GitHub Pages)

### 1. GitHub Pages を有効化する
1. リポジトリ (`https://github.com/33kasp33-cpu/eng`) の **Settings** を開く。
2. 左メニューの **Pages** をクリック。
3. **Build and deployment** の Source で **Deploy from a branch** を選択。
4. Branch を **`main`**（または `master`）、フォルダを **`/ (root)`** に設定して **Save** を押す。
5. 数十秒〜1分ほどで専用URL（例: `https://33kasp33-cpu.github.io/eng/`）が発行されます。

### 2. スマホでアクセスしてホーム画面に追加
1. スマホのブラウザ（iPhoneのSafari、AndroidのChrome）で上記URLを開く。
2. **「ホーム画面に追加」** を選択すると、ネイティブアプリ同様に全画面で起動できます。
3. マイク権限を許可することで、音声認識（STT）とネイティブ発音再生（TTS）が利用可能です。

## 🤖 Gemini API 設定ガイド（無料枠 500回/日）
1. [Google AI Studio](https://aistudio.google.com/) で無料の API Key を取得。
2. アプリ右上の **「設定 / API」** から API Key を入力して保存。
3. **推奨モデル**: `gemini-3.5-flash-lite`（無料枠で 1日 500リクエスト / 分間 15リクエスト利用可能）。

## 🩺 9項目セルフテストスイート (Diagnostics)
アプリ上部の「自己診断」タブから **「9項目テスト一括実行」** を押すことで、TTS、STT、LocalStorage、Gemini API、Gist、Drive入出力、TOEICエンジンなどの全モジュール健全性をワンクリックでテストできます。
