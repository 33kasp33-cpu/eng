# 目的
TOEIC Part 5の品詞識別問題に特化した「RTA（リアルタイムアタック）型 反射神経訓練Webアプリケーション」を実装せよ。
学習要素・余計な演出・冗長な解説を完全排除し、ミリ秒単位の反射速度のみを強制する仕様とすること。

# 技術スタック
- Single File（HTML / Tailwind CSS / Vanilla JS）または React (Next.js App Router)
- 外部DB不要、状態はLocalStrageに保存

# 画面仕様（超ミニマルUI）
- ダークモード基調（黒背景、高コントラスト）。
- 表示要素は以下の4点のみ：
  1. ミリ秒表示のカウントダウンタイマー（大きく中央上部）
  2. 現在の進捗（例：`STAGE 04 / 10`）
  3. 問題文（空欄 `_____` を含む1行の短文）
  4. 選択肢ボタン 4つ（A, B, C, D / キーボード [1][2][3][4] または [A][B][C][D] にバインド）

# ゲームループ＆コアロジック
1. **制限時間**
   - 1問あたりの制限時間は厳密に「3.00秒」。
   - 0.00秒になった瞬間、強制的に「TIMEOUT FAIL」となり即リセット（1問目へ戻る）。
2. **連続正解（ストリーク）と即時リセット**
   - ノルマ：10問連続正解。
   - 誤答時は画面が一瞬赤フラッシュし、判定理由（例：`[-tion = 名詞]`）を0.8秒だけ表示して即座にStage 1に強制リセット。
3. **遷移速度（ゼロ・レイテンシ）**
   - 正解時はアニメーションやウェイトを挟まず、0msで次の問題を描画する。
4. **クリア判定とスコア**
   - 10問連続正解達成時、合計タイム（例：`21.43s`）を表示。
   - ベストタイム（PB）をLocalStorageに保存し、常に画面隅に表示。
   - [SPACE]またはクリックで即座に次のRTAを開始可能。

# 収録データ（初期データとして30問以上内蔵すること）
TOEIC Part 5の典型的な品詞識別問題（文意を読まずに空欄前後と接尾辞だけで解ける問題）を配列で持たせること。

データ構造例：
[
  {
    "q": "The manager appreciated the _____ of the new scheduling system.",
    "options": ["efficient", "efficiency", "efficiently", "efficiencies"],
    "answer": 1,
    "trigger": "冠詞the + 前置詞ofの間 → 名詞 [-ty]"
  },
  {
    "q": "The committee will _____ review the proposal before making a decision.",
    "options": ["careful", "carefully", "carefulness", "caring"],
    "answer": 1,
    "trigger": "助動詞will + 本動詞の間 → 副詞 [-ly]"
  }
]

# 実装上の絶対要件
- モバイルタップおよびPCキーボード（A,B,C,D / 1,2,3,4）の双方でラグなく操作できること。
- 余計な設定画面、ログイン機能、BGM、長いリザルト演出は一切実装しないこと。
